# CQuests 1.16.0

Goes with CBosses 1.3.0.

## Changes

- Every world boss now stands on the ground and is centred on its hitbox, so it no longer floats, sinks or swings off to one side.
- World bosses are now about 3 to 3.5 blocks tall; the four mythic bosses (The Listener, Withered Tyrant, Ender Wyrm, Gale Sovereign) are 4 to 5 blocks.
- Hitboxes now match each boss's body, so hits land where you aim.
- Player data was already saved crash-safe (temp file, backup, atomic swap) and is unchanged.
