# Millstone Monk 1.3.9

Adds only the approved Millstone Monk as a regular 5,000 HP big/world boss. No chapter or season is assigned. Existing bosses, commands, arena data and rewards are preserved.

Its carved head, stone cheeks, folded collar, rooted moss sprouts, braced fists and turning axle wheel are shared by both plugins. Shockwave uses millwheel prayer, heal uses axle resonance, and quake and melee use stone palm. The rear axle is a 1.7x weak spot. Entrance, hurt and death have authored clips, without a decorative ring.

The Moonwake Manta and Thorncoil Basilisk remain review-only and are not included in the runtime roster.

## Installation

Stop the server, back up both existing JARs and data folders, replace only each plugin JAR, and start. Keep configuration and world data. The existing missing-default merger adds the new boss while retaining custom settings. A custom millstone_monk JSON override still takes priority over the bundled model. No resource pack is required.

## Rollback

Stop the server and restore the previous JARs and backed-up data folders together.
