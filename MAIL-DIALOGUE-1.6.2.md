# CQuests 1.6.2 — simpler mail

`/quest mail` now opens a native Minecraft dialogue on supported Java clients, like the settings-style screen. The inbox, letters, sent messages and replies all use the same screen style.

1. Choose a letter labelled with its sender and subject. New letters have a NEW marker.
2. Read the message with its sender and delivery date. Long letters have Next page and Previous page buttons.
3. Choose Reply, type in the message box and press Send. Ordinary villager answers open immediately; Sent letters & replies lets you reread them.
4. Back to inbox returns to the letter list. Close leaves mail.

Books are no longer part of the normal mail flow. Existing explicit book commands remain available for anyone who wants them. Older or unsupported clients receive locked inventory menus with a readable letter tooltip and navigation buttons; replying there uses the existing suggested chat command.

B.O.B's Reply button stays hidden until optional AI replies are configured. His original letters remain readable. The AI composer explains when messages and quest memories are sent to Google. Ordinary villagers and the rest of CQuests work without AI.

Existing delivery dates, read status, correspondence, player progress and configuration are retained. Replace the JAR while the server is stopped and keep the CQuests data folder. The 1.6.1 sentence animation and click-to-advance fix is included.
