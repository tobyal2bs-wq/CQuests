# CQuests 1.9.1

Every boss, mini boss and companion can now be tried with a test command. Nothing counts in a test, and only you see what it spawns.

## New test commands

* `/cq test bossnext` stops your current test fight and starts the next boss. Run it again and again to see all 11 bosses and mini bosses, one by one.
* `/cq test companion` makes Pip follow you for a minute, the way Pip does on escort quests. `/cq test bossstop` sends Pip home early.

Already there: `/cq test boss <quest>` for one boss, `/cq test all` for a clickable list, `/cq test bossphase` for half health with minions, `/cq test bossevent <event>` and `/cq test pip <bow|sword>`.

## Upgrading

Replace the jar and restart. No config changes are needed.
